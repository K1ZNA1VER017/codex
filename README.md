# ❖ CHRONICA 1C // КОДЕКС РАЗРАБОТЧИКА ❖
### Персональный веб-портал и трекер обучения под будущее трудоустройство

> **Траектория карьерного взлета:** От рутины эникея/выездного инженера во франчайзи 1С к высокооплачиваемой позиции **Junior+ / Middle 1С-Разработчик (In-House / Интегратор)** с зарплатной вилкой **110 000 — 160 000 ₽**.

---

## ⚔ Стек технологий

* **Frontend:** Чистый HTML5, CSS3 (монохромный Glassmorphism, нео-средневековые металлические текстуры, адаптивная верстка под все устройства), Vanilla JS (ES6+).
* **3D Графика:** **Three.js** — интерактивная 3D-модель «Астролябия Мастерства 1С» (вращающиеся хромированные кольца, светящееся ядро Элемента, частицы, реакция на клики мыши и общий процент готовности).
* **Backend:** PHP 8+ (чистый, структурированный, без тяжелых сторонних фреймворков).
* **База данных:** **MySQL** через **phpMyAdmin** на **OpenServer** (локально).
* **Архитектура:** Без обязательной регистрации/авторизации. Полная интеграция с MySQL через `api.php` + встроенный бесшовный fallback на `localStorage` при автономном запуске без сервера.

## 🚀 Инструкция по установке на OpenServer (локально)

### Шаг 1. Размещение файлов в OpenServer
1. Перейдите в корневую директорию вашего OpenServer (например, `C:\OSPanel\` или `D:\OpenServer\`).
2. В папке `domains\` создайте новую папку проекта, например `tracker-1c.local`.
3. Скопируйте все файлы из этой папки проекта (`index.php`, `config.php`, `api.php`, `database.sql`, `style.css`, `app.js`, `three_artifact.js`) внутрь `domains\tracker-1c.local\`.

### Шаг 2. Импорт базы данных через phpMyAdmin
1. Запустите OpenServer 6 (с включенным модулем **MySQL-8.4**).
2. Кликните по флажку OpenServer → **Инструменты** → **phpMyAdmin** (или откройте `http://127.0.0.1/openserver/phpmyadmin/`).
3. Войдите с логином `root` (пароль по умолчанию пустой).
4. В верхнем меню выберите вкладку **«Импорт» (Import)**.
5. Нажмите кнопку **«Выберите файл»** и укажите `database.sql` из папки проекта.
6. Нажмите кнопку **«Вперед» (Go)** внизу страницы.
   - Скрипт автоматически создаст базу данных `hightech` в кодировке `utf8mb4_unicode_ci` под MySQL 8.4 и заполнит ее всеми 16 подробными квестами!

### Шаг 3. Запуск и проверка
1. Откройте в браузере:
   ```
   http://tracker-1c.local/
   ```
2. В правом верхнем углу статус-бейдж покажет:
   **`✓ БД: MySQL (OpenServer)`**
3. Готово! Любое переключение статусов, добавление задач и редактирование заметок мгновенно записывается в базу данных MySQL.

## ⚙ Конфигурация MySQL (`config.php`)

По умолчанию в `config.php` заданы стандартные настройки OpenServer:
```php
<?php
/**
 * Настройки подключения к СУБД MySQL/MariaDB в OpenServer.
 * 
 * После импорта database.sql укажите здесь параметры вашей локальной БД.
 * В OpenServer 6 в поле host используйте имя модуля БД, например, MySQL-8.0 или MySQL-8.4.
 */
return [
    'host'     => 'MySQL-8.4',
    'dbname'   => 'hightech',
    'user'     => 'root',
    'password' => '',
    'charset'  => 'utf8mb4',
];
```
Если ваш MySQL в OpenServer слушает другой порт или пароль пользователя `root` изменен, вы можете скорректировать эти константы в файле `config.php`.

## 💎 Уникальные фичи портала

1. **Блок «Что я должен уметь после выполнения»**: Каждая задача снабжена списком конкретных навыков и проверочных критериев (hard skills).
2. **Артефакт на выходе (Deliverable)**: Четко зафиксировано, что является осязаемым подтверждением (репозиторий на Git, коллекция Postman, номерной сертификат 1С, оффер).
3. **Интерактивная 3D Астролябия**: Модель Three.js в реальном времени реагирует на прогресс выполнения задач — чем больше квестов закрыто, тем ярче светится ядро и интенсивнее вращаются орбитальные кольца.
4. **Редактор личных заметок**: Прямо на странице можно записать даты, контакты рекрутеров, номера заявок или заметки к коду, сохранив их в MySQL.
5. **Фильтры и живой поиск**: Мгновенный поиск по названиям, категориям (1С:Элемент, REST API, БСП, СКД, Интервью) и статусам квестов.
